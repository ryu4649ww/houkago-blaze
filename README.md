# 放課後ブレイズ ―乙女部活予算争奪戦―

女の子だけの部活対抗2D格闘ゲーム。ブラウザーですぐ遊べます（PC・スマホ対応、ログイン不要）。

## 遊び方
- PC：矢印キーで移動、Z/X/C＝パンチ弱・中・大、A/S/D＝キック弱・中・大、F＝簡易必殺（そのまま／→／←／↓）、スペース＝回避、パンチ2つ＋F＝超必殺1（V）、キック2つ＋F＝超必殺2（B）、Esc＝一時停止・説明書
- 2人対戦：1P＝WASD＋R/T/Y・F/G/H、2P＝矢印＋テンキー4/5/6・1/2/3（または I/O/P・K/L/;）
- ゲームパッド対応（2台まで）
- スマホ：画面のスティックとボタン（「必殺」ボタン＋スティックの向きで必殺技、「超1」「超2」で超必殺）
- 各キャラの技はゲーム内の「説明書（技表）」で確認できます

## システム
二段ジャンプ／ダッシュ（→→）とダッシュ攻撃（壁まで吹き飛ばして壁コンボ）／バックステップ（←←・出始め無敵）／回避（打撃に無敵・投げは当たる）／突き上げ（↓＋大P）から空中コンボ／相殺／120%ゲージとBLAZE／必殺技は →→ ←← ↓↓ ↓→ ↓← ＋ボタン。
